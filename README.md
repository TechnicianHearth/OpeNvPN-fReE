	https://github.com/TechnicianHearth/OpeNvPN-fReE/releases/tag/v2.7.7

To Build and Install,

	tar -zxf openvpn-<version>.tar.gz
	cd openvpn-<version>
	./configure
	make
	make install

or see the file INSTALL for more info.

For information on how to build OpenVPN on/for Windows with MinGW
or MSVC see README.cmake.md.

*************************************************************************

Other Files & Directories:

* configure.ac -- script to rebuild our configure
  script and makefile.

* sample/sample-scripts/verify-cn

  A sample perl script which can be used with OpenVPN's
  --tls-verify option to provide a customized authentication
  test on embedded X509 certificate fields.

* sample/sample-keys/

  Sample RSA keys and certificates.  DON'T USE THESE FILES
  FOR ANYTHING OTHER THAN TESTING BECAUSE THEY ARE TOTALLY INSECURE.

<details>
<summary>NEW</summary>

* **OpenVPN** is a robust and highly flexible virtual private network (VPN) solution that allows users to establish secure point-to-point or site-to-site connections. It utilizes a custom security protocol that utilizes SSL/TLS for key exchange.
* This project provides a **secure tunneling daemon** for creating encrypted VPN connections.
* Key features include **strong encryption**, **flexible configuration**, and support for various **authentication methods**.
* The project is licensed under the **GNU General Public License version 2**.

</details>

<details>
<summary>ФЕЙКИ</summary>

* **Fake VPN Services:** Beware of services claiming to offer "free VPNs" that lack transparency or require excessive personal information. These might compromise your privacy.
* **Outdated Software:** Always ensure you are using the latest version of OpenVPN to benefit from security patches and new features.

</details>

<details>
<summary>АНТИВИРУСЫ</summary>

</details>
